  • Province / จังหวัด - จังหวัด
  • District / อำเภอ - อำเภอ
  • Age / อายุ - อายุ (ปี)
  • Gender / เพศ - เพศ (ชาย/หญิง)
  • Status / สถานะ - สถานะ (เสียชีวิต / ผู้ป่วย)
  • Lat, Long / ละติจูด, ลองจิจูด - พิกัดจุดเกิดโรค
